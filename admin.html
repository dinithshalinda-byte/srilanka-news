⚙️ GitHub Settings (එක වරක් පමණක් පුරවන්න)

Token එකක් හදාගන්නේ කොහොමද?
1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
2. Generate new token → Repository access: Only select repositories → ඔයාගේ repo එක තෝරන්න
3. Permissions → Repository permissions → Contents: Read and write දෙන්න
4. Generate → Token එක copy කරගෙන පහල field එකට paste කරන්න

මේක browser එකේ save වෙනවා. ආයෙ පුරවන්න ඕන නෑ.
